O Frontend é a camada visual e interativa de um site ou aplicativo — basicamente, tudo aquilo com que o usuário interage diretamente na tela.

Os Três Pilares Fundamentais
HTML (HyperText Markup Language): É a estrutura e o esqueleto da página. Define onde ficam os títulos, parágrafos, botões, formulários e imagens.

CSS (Cascading Style Sheets): É a estilização e a estética. Define cores, fontes, espaçamentos, layouts e garante a responsividade (adaptação para celular e computador).

JavaScript (JS): É a lógica e a interatividade. Faz as coisas funcionarem dinamicamente — como abrir um menu ao clicar, enviar formulários sem recarregar a página ou carregar novos posts no feed.
