Repositórios Remotos

Um repositório remoto é uma versão do seu projeto que está hospedada na internet ou em uma rede. O
mais comum é utilizar serviços como o GitHub, GitLab ou Bitbucket. Ter um repositório remoto permite
a colaboração de varias pessoas em equipe, ficando mais fácil para projetos; o backup poderá ser feito, colocando o seu código sendo seguro; e também terá mais mobilidade com seu projeto que poderá clonar e acessar em qualquer local

Principais comandos
git remote -v: mostra os repositórios remotos configurados.
git push: envia as alterações para o repositório remoto.
git pull: baixa as alterações do repositório remoto para o computador.
